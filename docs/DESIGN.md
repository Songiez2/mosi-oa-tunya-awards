## Visual Language
- Core visual signature: gold metallic gradient text and borders using linear-gradient(135deg, #C9A227 0%, #F5D26B 40%, #C9A227 70%, #8B6914 100%) — applied to headings, trophy icons, and interactive dividers
- Material & depth: dark panels with gold border-glow (box-shadow: 0 0 20px rgba(201,162,39,0.15)), layered glassmorphism cards (backdrop-blur + rgba(201,162,39,0.05) backgrounds), subtle radial spotlight on hero
- Containers & buttons: cards with 1px gold border at 30% opacity, gold gradient fill on primary CTA buttons, secondary uses dark surface + gold text, pill-shaped vote badges
- Layout rhythm: alternating dark sections (#0D0D0D vs #111) with gold accent lines as section dividers; gold used sparingly on icons, stats numbers, and active navigation states

## Animation
- Entrance: stat numbers count up from 0 with ease-out 1200ms; nominee cards fade-in with staggered 80ms delay
- Interaction: gold glow pulse on Vote button hover (box-shadow expands 200ms ease); card lift with translateY(-4px) 150ms
- Scroll / transition: sections animate in on viewport enter with opacity 0→1 translateY 20px→0 over 600ms

## Forbidden
- Large flat color fills for hero (use gradient/texture/overlay instead)
- Generic blue/purple gradients
- Emoji in navigation or headings
